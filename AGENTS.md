# Building Blocks

Build a static read-only website for GitHub Pages. Keep asset and internal links compatible with repository subpaths and direct page refreshes. Do not introduce a backend, accounts, forms, visitor data entry, cookies, tracking, analytics, or browser storage. Prefer locally bundled assets. Keep paper summaries sourced and mark schematic examples and conceptual links clearly.

Use Node.js 22 and pnpm 11.19.0. Run `pnpm build` and `pnpm verify` before delivery. Never commit node_modules, dist, archives, credentials, or environment files.
